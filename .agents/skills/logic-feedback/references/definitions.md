# 定義集（FBの判定基準）

FBはすべてここの定義に照らして行う。一般的な教科書の定義ではなく、本人が決めたこの定義を正とする。

## MECE

**定義**: ある命題を、決めた観点にしたがって同じ具体レベルで具体化し、抜け漏れダブりなく網羅する。

成立条件:
1. 観点（分け方）が明示されている。解決したい課題に合わせて選ばれている（3C、4P など）
2. 分類の手法は一つだけ。複数の観点が混ざっていない
3. 命題を「一段階だけ」具体化した要素になっている。要素同士の具体レベルが揃っている
4. 客観的に「抜け漏れダブりがない」とわかる

メリット: 考慮漏れを防ぎやすい／全体と部分の対応関係がわかりやすい。
注意: 厳密に洗い出すのは難しく、「MECEに」がただの号令になりがち。

## 論理的思考

**定義**: ある根拠をもとに、第三者が検証可能なルールに従って結論を導き出す思考。

推論の型（結論をどう導くか）:
- **演繹**: 前提となる複数のルール・事実から、形式的に必然性のある結論を導く。「AならばB」「Aである」→「ゆえにBである」
- **帰納**: 複数の個別事例に共通する性質から、一般化した結論を導く
- **アブダクション（仮説形成）**: 観察された事実を最もよく説明できる仮説を導く

補助する技法・道具（推論そのものではなく情報整理の手段）:
- MECE: 抜け漏れダブりなく分類・網羅する
- 5W1H: Who / What / When / Where / Why / How の観点でチェックする

## クリティカルシンキング

**定義**: 根拠・思考の過程・結論のそれぞれについて、客観的に正しいかを一つ一つ検証・吟味する思考。

前提:
- 論理的思考を内包する（結論を導く過程そのものは論理的思考のルールに従う）
- 固有の要素は「検証・吟味」という視点を加える点

構成要素（何を検証するか）:
- **批判的検証の姿勢**: 根拠と結論の一つ一つが間違っていないか確認する。「否定・攻撃」ではなく「妥当性の確認」
- **認知バイアスの自覚と排除**: 思考は心理的バイアスで歪みやすいことを前提に、意識的に取り除く
- **メタ認知**: 自分の思考過程を一段上から客観視し、バイアスや論理の飛躍がないか確認する

## 目指す状態

- 業務で全体と個別の対応関係を把握し、安心して進められる
- 業務の情報を構造的に把握している
- 抽象と具体の関連性を把握できている
- 構造的な理解がクセになっている

## 現状の困りごと（FBで重点的に見る点）

- 会話で「何を言っているのかわからない」と指摘される → 話すことの整理ができていない
- 「検討してください」と言われても、何をどう検討するのかわからない → 仕事の進め方を構造的に分解できていない
